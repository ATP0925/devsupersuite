## 2. Stack Exchange Help Center Anti-Spam Compliance Rules

Stack Exchange community moderators ruthlessly downvote and delete promotional spam. To guarantee that answers remain permanently upvoted and protected from moderation flags, every answer must strictly adhere to the following 5 rules:

### Rule 1: The "Self-Contained Answer" Mandate
An answer must **fully solve the user's problem directly on the page**. A user must be able to copy the provided code snippet, paste it into their editor or terminal, and achieve their goal **without clicking any external link**.
- ❌ *"You can solve this using my tool at example.com/tool."* (Instant flag & deletion).
- ✅ Complete, copy-pasteable Tree-sitter query, Python script, or git hook that solves the root issue directly, followed by an optional reference to an automated utility.

### Rule 2: Mandatory Explicit Disclosure
Whenever referencing DevSuperSuite or its client-side WebAssembly demo, Stack Exchange policy strictly requires clear, unambiguous affiliation disclosure:
> *"Disclosure: I am part of the engineering team at DevSuperSuite, an open local-first developer utility for AST interface slicing."*

### Rule 3: Zero Commercial Language or Pricing
Never mention commercial licensing, prices, or discount codes inside a Stack Overflow answer:
- ❌ *"Use coupon code REDDIT-VIP for $24 lifetime."* (Triggers automated spam flags).
- ❌ *"DevSuperSuite is the best, revolutionary AI optimizer."*
- ✅ Keep the tone purely academic, technical, and objective. Point only to the free, zero-signup client-side WebAssembly playground (`https://devsupersuite.web.app`).

### Rule 4: Concrete Code & Mathematical Formatting
- Use standard Markdown code blocks with syntax highlighting (`python`, `rust`, `go`, `typescript`, `bash`).
- Use LaTeX formatting for mathematical expressions: $H(X) = -\sum P(x) \log_2 P(x)$ and transformer attention formulas.
- Provide real-world benchmark tables comparing raw tokens vs sliced tokens.

### Rule 5: 100% Brand Anonymity Protocol
All Stack Overflow profiles, answers, and comments must represent:
- **Entity**: `DevSuperSuite Community Engineering`
- **Contact**: `community@devsupersuite.com`
- **Prohibition**: Zero disclosure of founder personal names, residential locations, or private personal emails.
