### Cynical HN Comment:
> *"What languages are actually supported by the AST parser?"*

### Engineered Systems Response:
We currently support full AST interface extraction and Shannon entropy scanning for:
- TypeScript / JavaScript (including TSX / JSX)
- Python (classes, async functions, type hints, dataclasses)
- Rust (structs, traits, impl blocks, enums, pub fn signatures)
- Go (structs, interfaces, func signatures, package contracts)
- C / C++ (headers, class declarations, function prototypes)
- Java / Kotlin / C# (classes, interfaces, method headers)
- SQL / Prisma / GraphQL schemas

Support for additional languages is driven by standard Tree-sitter grammar modules.
